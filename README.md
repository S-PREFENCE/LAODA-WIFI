# 劳大象棋 · 网页版（Laoda Xiangqi）

纯前端劳大象棋游戏：双人对战 + 三档人机 + 16 关残局挑战，含音效、悔棋、重开、着法记录、界面主题切换。东方雅致视觉风格，无任何后端依赖，可直接部署到 GitHub Pages。

---

## 功能一览

- **双人对战**：红黑轮流，标准劳大象棋规则，红方先走。
- **人机对战 · 三档难度**：入门 / 进阶 / 大师。每一档都比上一档**明显更强**（见下方「难度阶梯验证」）。
- **残局挑战 · 16 关**：每关都极难，**全部自由解锁**，无需逐关通关即可任选；`localStorage` 可选保存主题设置；防守方由大师级 AI 把守。
- **音效与打击感**：Web Audio API 程序化合成（零音频文件）——落子、吃子、将军、胜、负、违规、点击；落子/吃子带冲击环与棋子缩放动画。
- **界面主题**：4 种背景配色（漆木 / 玉绿 / 水墨 / 紫霄），侧边栏一键切换并自动记忆。
- **对局辅助**：悔棋、重开、着法记录（棋谱）、俘获棋子展示。
- **侧边操作栏**：东方雅致·玻璃拟态风格，所有功能集中右侧。

## 技术架构

| 模块 | 文件 | 职责 |
|------|------|------|
| 常量与开局 | `js/constants.js` | 棋子定义、标准开局、子力价值、位置价值表 |
| 棋盘模型 | `js/board.js` | 9×10 棋盘、克隆、合法性、飞将检测 |
| 规则引擎 | `js/rules.js` | 七子走法、将军/将死/困毙、飞将过滤 |
| AI | `js/ai.js` | negamax + α-β 剪枝 + 静止搜索 + 三档难度 |
| 音效 | `js/audio.js` | Web Audio 程序合成音效，首次交互后解锁 |
| 残局 | `js/endgames.js` | 16 关阵型定义与棋盘构建 |
| 界面 | `js/ui.js` | SVG 棋盘绘制、点击交互、侧边栏面板 |
| 控制器 | `js/game.js` | 模式/难度/先手/悔棋/求和/重开/关卡逻辑 |
| 启动 | `js/main.js` | DOM 就绪后初始化并解锁音频 |

- **引擎**：完整规则——车/马/炮/相/象/仕/士/帅/将；蹩马腿、塞象眼、炮架、飞将、兵过河横走、将军/将死/困毙。
- **AI**：`negamax + α-β 剪枝 + 静止搜索(quiescence)` + 评估函数（子力价值 + 位置价值表 PSQT）。三档难度通过**搜索深度递增**（`easy:2` → `medium:3` → `hard:5`）并配合静止搜索与随机扰动实现逐级变强。
- **音效**：纯程序合成，不依赖任何音频文件。
- **Node 自检**：所有 JS 模块同时兼容浏览器与 Node（`typeof window !== 'undefined' ? window : globalThis`），可在无浏览器环境验证引擎/AI/残局。

## AI 难度阶梯验证

运行 `node ladder_test.js`，在 16 关残局根节点统计各档「识别为强制将死」的关卡数：

| 难度 | 识别强制将死 | 说明 |
|------|-------------|------|
| 入门 easy | **0** / 16 | 深度 2、无静止搜索、含随机扰动，仅看子力 |
| 进阶 medium | **12** / 16 | 深度 3 + 静止搜索 |
| 大师 hard | **13** / 16 | 深度 5 + 静止搜索，独有 mate-in-5（如「双车夹攻」）|

`hard` 相对 `easy` 的根评分领先高达约 **999000** 分（≈一车的子力价值），阶梯关系为 `easy < medium < hard`，满足「每升一档明显更强」。

## 联机对战（内网双人 · 零依赖 · 零外网）

在公司内网（无法连接外网）环境下，与同事实时对弈。**棋步数据只在你们的内网两点间流转，不经过任何外部服务器**，符合信息安全要求。

### 架构
- 一台内网机器运行 `server.js`（Node）或 `server.py`（Python）——它**同时托管前端页面 + 中转棋步**（WebSocket）。
- 两名玩家各自用浏览器打开 `http://<主机内网IP>:3000`，**纯浏览器、零安装**。
- 一方「创建房间」拿到 6 位房间码，另一方「加入房间」输码即可开局。
- 服务端做**轻量权威**：Node 版复用前端同一套规则引擎逐步校验合法性，防两端不同步；Python 版做结构校验（走子方/轮次/越界/不可自吃）+ 中继。

### 启动主机（任选其一，均已零依赖）
```bash
# 方式 A：Node（推荐，带完整规则权威校验）
node server.js            # 默认端口 3000，可加参数指定：node server.js 8080

# 方式 B：Python（无 Node 时；结构校验 + 中继）
python server.py

# 懒人方式：双击 start.bat（Windows）/ 运行 start.sh（Linux/macOS），自动检测 node 或 python
```
启动后控制台会打印「内网访问」地址（如 `http://192.168.1.50:3000`），把它发给同事即可。

### 玩家联机步骤
1. 主机运行服务端；两名玩家浏览器打开主机的内网地址。
2. 一方点「创建房间」→ 得到房间码；另一方在输入框填房间码 → 点「加入」。
3. 双方自动开局（红先黑后）；轮到对方时本地棋盘不可操作，走子实时同步并带打击感反馈。
4. 任一方可「认输」结束对局；对手离开时会有提示。

### 安全说明
- 整个联机链路**完全在内网**，不使用任何 CDN、外部字体或外部 API（前端 `xmlns` 命名空间不发起网络请求）。
- 服务端代码全部为标准库手写、可逐行审计，便于过信息安全审查。
- 若要对外网开放，请勿直接暴露此内网服务；本工具设计目标即内网对弈。

